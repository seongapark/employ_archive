# 운영 사고 기록

자동 수집(로컬 작업 스케줄러 10·15시, 발표일 재수집 매시간)에서 생긴 실패를 한 줄씩 적는다.
알림 이슈는 `collect-alert` 라벨로 자동으로 열리고, 매일 수집이 전부 성공하면 자동으로 닫힌다.
이슈에는 오류 문구만 남으므로 원인과 조치는 여기에 적는다.

**근본 해결** 표기
- 예: 같은 원인으로는 다시 실패하지 않도록 코드를 고쳤다.
- 부분: 피해는 줄였지만 원인은 우리 밖에 있어 다시 날 수 있다.
- 불필요: 일시적 장애. 다음 회차에 저절로 성공했다.
- 아니오: 사람 손이 필요하다.

## 새 사고가 났을 때

1. `logs/` 의 그 시각 로그에서 `::error::` 줄과 `ok=False` 줄을 찾는다.
2. 같은 오류가 위 표에 있으면 "재발 시 확인할 곳" 부터 본다.
3. 원인을 확인하고 조치한 뒤 이 표에 한 줄을 더한다. 일시 장애도 적는다 — 반복되는지 알아야 한다.
