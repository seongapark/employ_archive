# 질의응답 도메인취합 — 단계 A 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 유형별 배타 분기를 **도메인 답변자 + 취합기** 구조로 갈아끼우되, 답이 나오는 원천은 지금과 같은 셋(고용동향·고용전망·원인탐색)으로 두어 회귀를 먼저 털어낸다.

**Architecture:** 답변자는 `applies(슬롯)` 와 `answer(deps, 슬롯)` 둘만 가진 모듈이다. 라우터는 도메인 표를 갖지 않고 `applies` 를 물어본다. 답변자는 LLM 을 쓰지 않고 근거·숫자모음·허용텍스트만 낸다. 문장을 쓰는 것은 취합기(LLM 2패스) 한 곳뿐이고, 검증은 **문장 단위**로 돌아 어긋난 문장만 버린다.

**Tech Stack:** Cloudflare Workers (ESM, `.mjs`) · D1 (SQLite) · `node --test` · OpenAI `gpt-4o-mini` (구조화 출력)

**Spec:** `docs/superpowers/specs/2026-09-10-질의응답-도메인취합-design.md`

## Global Constraints

- **테스트는 네트워크에도 LLM 에도 나가지 않는다.** `deps.db`·`deps.llm`·`deps.kv` 는 전부 주입이며, 가짜는 **실물보다 관대하면 안 된다**(가짜 KV 가 `String(v)` 를 대신 해 줘 IP 할당량이 통째로 무효였던 전례가 있다).
- **숫자는 LLM 이 만들지 않는다.** 답변에 등장하는 모든 숫자는 답변자가 낸 `숫자모음`·`허용텍스트` 안에 있어야 한다.
- **못 하는 것과 안 한 것을 뭉개지 않는다.** `한계`(못 준다) · `미확인`(확인 못 했다) · `안부름`(이 질문에 해당하지 않아 호출하지 않았다)은 각각 다른 필드다.
- **`core/` 는 프로토콜을 모른다.** HTTP·MCP 는 `api/` 가 감싼다.
- 어휘표를 두 벌 두지 않는다. 파생시킬 수 있으면 파생시킨다(`축_SYN` 이 `카테고리_SYN` 에서 파생되는 것과 같은 규율).
- 파일은 `domains/ask/worker/src/` 아래. 답변자는 `answerers/<도메인>.mjs`.
- 커밋 메시지는 한국어. 끝에 `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>` 와 `Claude-Session:` 두 줄을 붙인다.

```js
// 라우터는 **도메인 표를 갖지 않는다.** 어느 질문에 어느 도메인이 답할 수 있는지는
// 그 도메인이 가장 잘 알고, 중앙에 표를 두면 도메인이 늘 때마다 두 곳을 고쳐야 한다.
// 유형을 도메인이 갖는다는 결정(스펙 §1-2)과 같은 이유다.

export const ANSWERERS = [];

export function pickAnswerers(슬롯, 목록 = ANSWERERS) {
  const 부름 = [];
  const 안부름 = [];
  for (const a of 목록) {
    let v;
    try {
      v = a.applies(슬롯);
    } catch (e) {
      // 한 도메인의 버그가 나머지를 끌고 내려가지 않는다. 다만 조용히 빠지지도 않는다.
      안부름.push({ 도메인: a.도메인, 사유: `적용 여부 판단 중 오류: ${e?.message ?? e}` });
      continue;
    }
    if (v === true) 부름.push(a);
    else if (v && typeof v === 'object' && v.ok === false) {
      안부름.push({ 도메인: a.도메인, 사유: v.사유 });
    } else {
      안부름.push({ 도메인: a.도메인, 사유: '이 질문에 해당하지 않는다' });
    }
  }
  return { 부름, 안부름 };
}
```

`domains/ask/worker/src/answerers/employment.mjs` 를 만들고, `core/ask.mjs` 의 다음을 **주석까지 그대로** 옮긴다: `축_BREAKDOWN` · `축_지목없음` · `관측축` · `보수적` · `비교기준` · `수치조회`. 그 위에 계약을 씌운다.

```js
const answerer = {
  도메인: 'employment',
  applies(슬롯) {
    if (!슬롯?.주제) return { ok: false, 사유: '주제가 비어 어떤 통계를 볼지 정할 수 없다' };
    return true;
  },
  async answer(deps, 슬롯) {
    const [a, b] = 슬롯.출처 ?? [];
    if (a && b) {
      const c = await compare(deps, { source_a: a, source_b: b });
      const q = await 수치조회(deps, { ...슬롯, 집단축: [] },
                               { 출처: [a, b], 비교하한: c.비교가능 });
      return 계약(q, { 유형: '출처비교', 비교: c, 한계: [...c.설명, ...q.한계] });
    }
    return 계약(await 수치조회(deps, 슬롯), { 유형: '수치조회' });
  },
};
export default answerer;
```

`계약()` 은 이 파일 안의 작은 함수로, 조회 결과에 `도메인`·`유형` 을 붙이고 **`숫자모음`·`허용텍스트` 를 여기서 만든다**:

```js
// 숫자모음·허용텍스트를 답변자가 만든다. 호출부 한 곳에서 조립하면 새 카드가 생길
// 때마다 빠뜨린다 — 전망 숫자를 빠뜨려 정상 답변이 통째로 버려진 적이 있다(2026-09-09).
function 계약(q, extra) {
  const r = { 도메인: 'employment', 근거: [], 한계: [], 미확인: [], ...q, ...extra };
  r.숫자모음 = [...numbersIn(r.근거 ?? [])];
  r.허용텍스트 = [...new Set([
    ...(r.한계 ?? []),
    ...(r.비교?.설명 ?? []),
    ...[...(r.라우팅?.불가 ?? []), ...(r.라우팅?.부분 ?? [])].map((x) => x.사유),
    ...(r.근거 ?? []).flatMap((e) => [e.유의성사유, e.우회경로, e.사유]),
  ].filter((s) => typeof s === 'string' && s))];
  return r;
}
```

```js
// **합집합으로 대조한다.** 문장이 두 출처를 밝혔으면 두 집합을 합쳐서 본다 — 한쪽만
// 보면 "관측은 5551인데 전망은 12.3 늘어난다" 같은 정상 문장이 버려진다.
export function verifySentences(문장들, { 숫자모음 = {}, 허용텍스트 = {} } = {}) {
  const 통과 = [], 버림 = [];
  for (const s of 문장들 ?? []) {
    const 출처 = s.출처 ?? [];
    const allowed = new Set(출처.flatMap((d) => 숫자모음[d] ?? []));
    for (const d of 출처) for (const n of numbersInText(허용텍스트[d] ?? [])) allowed.add(n);
    const 위반 = [...new Set(extractNumbers(s.글).filter((n) => !allowed.has(n)))];
    const 인용밖 = (s.인용 ?? []).filter((c) =>
      !출처.some((d) => (허용텍스트[d] ?? []).some((t) => t.includes(c.대목))));
    if (!위반.length && !인용밖.length) { 통과.push(s); continue; }
    버림.push({ 문장: s, 위반,
                진단: [...진단하기(위반, allowed),
                       ...인용밖.map((c) => ({ 인용: c, 판정: '인용밖' }))] });
  }
  return { 통과, 버림 };
}
```
