# 연구보고서 아카이브 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** KLI·KEIS·KDI·KIET 네 기관의 2021년 이후 고용·노동 보고서를 한곳에서 검색하고 주제로 다시 찾을 수 있게 하는 여섯 번째 도메인을 만든다.

**Architecture:** 기관별 파서가 게시판 목록·상세를 긁어 판정 없이 `sources/raw/` 에 넣는다(`collect.py`). 고용 여부 판정과 `data/*.json` 생성은 `keywords.json` 을 읽는 `build.py` 가 따로 한다. 화면은 기존 도메인과 같은 정적 ES 모듈 PWA 이며, 목록용 `reports.json` 만 먼저 받고 초록은 검색창 포커스 시점에 받는다.

**Tech Stack:** Python 3.12, pydantic v2, curl_cffi, lxml, pytest / 브라우저 ES 모듈(테스트는 `node --test`)

**Spec:** `docs/superpowers/specs/2026-09-10-연구보고서-아카이브-design.md`

**작업 위치:** 워크트리 `~/Desktop/연구보고서-작업`, 브랜치 `reports/archive`. 다른 세션과 폴더를 공유하지 않는다.

## Global Constraints

- **수집기는 판정하지 않는다.** `collect.py` 는 게시판에 있는 것을 전부 `sources/raw/` 에 넣고, `employment` 판정과 `data/*.json` 생성은 `build.py` 만 한다. (스펙 §5-3)
- **테스트는 네트워크에 나가지 않는다.** 파서 테스트는 `domains/reports/tests/fixtures/` 의 고정 HTML 만 읽는다. `collect.main` 은 `collectors` 를 주입받으면 네트워크 호출이 꺼진다.
- **기관 URL 을 코드에 박지 않는다.** 게시판 주소·페이지 파라미터·수집 여부는 전부 `data/boards.json` 에 있다.
- **2021-01-01 이후만 담는다.** 목록을 페이지 넘기다 그 이전 발간일이 나오면 그 게시판을 멈춘다.
- **원문 PDF 를 저장소에 받지 않는다.** `file_url` 은 링크로만 남는다.
- **화면은 `date_precision` 보다 정밀하게 표기하지 않는다.** `month` 면 `2025.12`, `year` 면 `2025년`.
- 요청 사이 지연 기본 **1.0초**, 회차당 **기관별 상세 조회 상한 40건**.
- **`hub/`·`core/`·`tools/`·`README.md` 는 Task 21 에서만 건드린다.** 다른 세션과 겹치는 파일이다.
- 새 의존성 없음. `pydantic`·`curl_cffi`·`lxml`·`pytest` 는 `requirements.txt` 에 이미 있다.
- 주석·문서·커밋 메시지는 한국어. 커밋은 `feat(reports):` / `docs(reports):` 형태.
- `git add -A` 금지. 항상 `git commit -- <경로>` 로 경로를 지정한다.

```python
"""보고서 한 건의 모양과 날짜 정규화.

이 모듈은 기관도 HTML 도 모른다. 문자열과 dict 만 다루므로 네 기관을 안 거치고
테스트가 돈다.
"""
from __future__ import annotations

import calendar
import re
from typing import Literal, Optional

from pydantic import BaseModel, Field, field_validator

CUTOFF = '2021-01-01'

DatePrecision = Literal['day', 'month', 'year']

_DAY = re.compile(r'^(\d{4})\D+(\d{1,2})\D+(\d{1,2})\D*$')
_MONTH = re.compile(r'^(\d{4})\D+(\d{1,2})\D*$')
_YEAR = re.compile(r'^(\d{4})\D*$')


def normalize_published(raw: str) -> tuple[str, str]:
    """발간일 문자열을 (ISO 날짜, 정밀도) 로 바꾼다.

    부분 날짜는 정렬이 깨지지 않게 월말·연말로 채우되, 채웠다는 사실을
    정밀도로 남긴다. 화면은 이 정밀도보다 자세히 적지 않는다.
    """
    s = (raw or '').strip()
    m = _DAY.match(s)
    if m:
        y, mo, d = (int(x) for x in m.groups())
        return f'{y:04d}-{mo:02d}-{d:02d}', 'day'
    m = _MONTH.match(s)
    if m:
        y, mo = (int(x) for x in m.groups())
        last = calendar.monthrange(y, mo)[1]
        return f'{y:04d}-{mo:02d}-{last:02d}', 'month'
    m = _YEAR.match(s)
    if m:
        return f'{int(m.group(1)):04d}-12-31', 'year'
    raise ValueError(f'발간일을 읽을 수 없다: {raw!r}')


def report_id(org: str, native_id: str) -> str:
    """기관이 부여한 번호를 그대로 쓴다 — 재수집해도 안 흔들린다."""
    return f'{org}-{native_id}'


class RawReport(BaseModel):
    """수집기가 만드는 모양. 판정 필드가 없다."""
    id: str
    org: str
    board: str
    series: str
    title: str
    authors: list[str] = Field(default_factory=list)
    published: str
    date_precision: DatePrecision
    pages: Optional[int] = None
    landing_url: str
    file_url: Optional[str] = None
    abstract: Optional[str] = None
    toc: list[str] = Field(default_factory=list)
    collected_at: Optional[str] = None

    @field_validator('published')
    @classmethod
    def _after_cutoff(cls, v: str) -> str:
        if v < CUTOFF:
            raise ValueError(f'{CUTOFF} 이전은 담지 않는다: {v}')
        return v


class Report(RawReport):
    """build 가 판정을 붙인 모양."""
    employment: bool
    matched: list[str] = Field(default_factory=list)
```

```python
import re
from pathlib import Path
from typing import Optional

BOARDS_PATH = Path(__file__).resolve().parent.parent / 'data' / 'boards.json'

# 메뉴에서 "목록 게시판"으로 볼 주소. 상세·다운로드·정적 페이지는 제외한다.

class Board(BaseModel):
    id: str
    org: str
    name: str
    series: str
    list_url: str
    item_re: str
    page_param: Optional[str] = None
    page_size_param: Optional[str] = None

    """호스트를 뺀 경로+질의. 상대·절대 주소를 같은 자로 잰다."""

    return parts.path + (('?' + parts.query) if parts.query else '')

    known = {_key(b.list_url) for b in boards if b.org == org}
    found: list[str] = []

        if not _LIST_HREF.search(href):

        if _key(href) in known or href in found:
```

```python
"""수집기가 공유하는 얇은 네트워크 계층.

기관 사이트는 간헐적으로 502를 준다. 한 번의 일시적 실패로 그 게시판이 통째로
비지 않도록 몇 번 다시 시도한다. 인코딩을 안 알려주는 국내 사이트가 있어
utf-8 → euc-kr 순으로 본다.
"""
from __future__ import annotations

import time
from typing import Callable, Optional

from curl_cffi import requests as cf_requests


def _default_fetch(url: str, timeout: int):
    return cf_requests.get(url, impersonate='chrome', timeout=timeout)


def _decode(content: bytes, encoding: Optional[str]) -> str:
    order = [encoding] if encoding else []
    order += ['utf-8', 'euc-kr', 'cp949']
    for enc in order:
        if not enc:
            continue
        try:
            return content.decode(enc)
        except (UnicodeDecodeError, LookupError):
            continue
    return content.decode('utf-8', errors='replace')


def get_text(url: str, *, timeout: int = 60, tries: int = 3,
             sleep: Callable[[float], None] = time.sleep,
             fetch: Optional[Callable] = None) -> str:
    call = fetch or _default_fetch
    last: Exception | None = None
    for attempt in range(1, tries + 1):
        try:
            resp = call(url, timeout=timeout)
            resp.raise_for_status()
            return _decode(resp.content, getattr(resp, 'encoding', None))
        except Exception as exc:       # noqa: BLE001 — 무엇이든 다시 시도한다
            last = exc
            if attempt == tries:
                break
            sleep(2.0 * attempt)
    raise last            # type: ignore[misc]


class Throttle:
    """요청 사이 간격을 지킨다. 게시판 예의는 코드로 강제한다."""

    def __init__(self, delay: float = 1.0,
                 sleep: Callable[[float], None] = time.sleep,
                 now: Callable[[], float] = time.monotonic):
        self.delay = delay
        self._sleep = sleep
        self._now = now
        self._last: Optional[float] = None

    def wait(self) -> None:
        t = self._now()
        if self._last is not None:
            gap = self.delay - (t - self._last)
            if gap > 0:
                self._sleep(gap)
        self._last = self._now()
```

```python
"""sources/raw/ 읽기·병합·저장. 판정은 하지 않는다."""
from __future__ import annotations

import json
from pathlib import Path

from .models import RawReport

RAW_ROOT = Path(__file__).resolve().parent.parent / 'sources' / 'raw'


def raw_path(board_id: str, org: str, root: Path | str | None = None) -> Path:
    return Path(root or RAW_ROOT) / org / f'{board_id}.json'


def load_raw(path: Path | str) -> list[RawReport]:
    p = Path(path)
    if not p.exists():
        return []
    return [RawReport.model_validate(r)
            for r in json.loads(p.read_text(encoding='utf-8'))]


def save_raw(path: Path | str, records: list[RawReport]) -> None:
    p = Path(path)
    p.parent.mkdir(parents=True, exist_ok=True)
    rows = [r.model_dump(mode='json')
            for r in sorted(records, key=lambda r: r.id)]
    p.write_text(json.dumps(rows, ensure_ascii=False, indent=2) + '\n',
                 encoding='utf-8')


def _same(a: RawReport, b: RawReport) -> bool:
    """collected_at 을 뺀 나머지가 같으면 같은 관측이다."""
    x = a.model_dump(exclude={'collected_at'})
    y = b.model_dump(exclude={'collected_at'})
    return x == y


def upsert(existing: list[RawReport],
           incoming: list[RawReport]) -> tuple[list[RawReport], list[str]]:
    by_id = {r.id: r for r in existing}
    added: list[str] = []
    for rec in incoming:
        old = by_id.get(rec.id)
        if old is None:
            by_id[rec.id] = rec
            added.append(rec.id)
        elif not _same(old, rec):
            by_id[rec.id] = rec
    return sorted(by_id.values(), key=lambda r: r.id), added


def load_all_raw(root: Path | str | None = None) -> list[RawReport]:
    base = Path(root or RAW_ROOT)
    if not base.is_dir():
        return []
    out: list[RawReport] = []
    for p in sorted(base.rglob('*.json')):
        out.extend(load_raw(p))
    return out
```

```python
from __future__ import annotations

import re
from urllib.parse import urljoin

from ..boards import Board
from ..models import RawReport, normalize_published, report_id

BASE = 'https://www.kli.re.kr'


def list_url(board: Board, page: int) -> str:
    sep = '&' if '?' in board.list_url else '?'
    return f'{board.list_url}{sep}nPage={page}'


def parse_list(html: str, board: Board) -> list[dict]:
    items: list[dict] = []
    seen: set[str] = set()
    # Step 2 에서 확인한 항목 블록 단위로 자른다.
    for block in re.split(r'(?=<li[^>]*>)', html):
        m = re.search(board.item_re, block)
        if not m:
            continue
        native_id = m.group(1)
        if native_id in seen:
            continue
        href = re.search(r'href="([^"]*' + board.item_re + r'[^"]*)"', block)
        date = re.search(r'(20\d{2}[-.\s]+\d{1,2}(?:[-.\s]+\d{1,2})?)', block)

        if not (href and date and title):

        items.append({
            'native_id': native_id,
            'detail_url': urljoin(BASE, href.group(1).replace('&amp;', '&')),
            'published_raw': date.group(1).strip(),
            'title': title.group(1).strip(),
        })
    return items


def parse_detail(html: str, item: dict, board: Board) -> RawReport:
    published, precision = normalize_published(item['published_raw'])
    authors = _authors(html)
    return RawReport(
        id=report_id('kli', item['native_id']),
        org='kli',
        board=board.id,
        series=board.series,
        title=item['title'],
        authors=authors,
        published=published,
        date_precision=precision,
        pages=_pages(html),
        landing_url=item['detail_url'],
        file_url=_file_url(html),
        abstract=_abstract(html),
        toc=_toc(html),
```

```python
KDI 는 한 게시판 안에 성격이 다른 문서가 섞인다 — 기타보고서 게시판에는
예비타당성조사·타당성 재조사 보고서가 함께 올라온다(실측 5종). 그래서
boards.json 의 category_keep 으로 분류를 걸러낸다.
"""
from __future__ import annotations

import re
from urllib.parse import urljoin

from ..boards import Board
from ..models import RawReport, normalize_published, report_id

BASE = 'https://www.kdi.re.kr'

_CATEGORY = re.compile(r'<b[^>]*class="i15"[^>]*>([^<]+)</b>')
_TITLE = re.compile(r'<strong[^>]*>([^<]+)</strong>')
_PAGES = re.compile(r'<span>\s*(\d+)\s*p\s*</span>')
_FILE = re.compile(r"location\.href='(/file/download\?[^']+)'")
_DATE = re.compile(r'(20\d{2}[-.]\s?\d{1,2}(?:[-.]\s?\d{1,2})?)')


def list_url(board: Board, page: int) -> str:
    sep = '&' if '?' in board.list_url else '?'
    return f'{board.list_url}{sep}{board.page_param or "page"}={page}'


def parse_list(html: str, board: Board) -> list[dict]:
    items: list[dict] = []
    for block in re.split(r'(?=<li[^>]*>)', html):
        m = re.search(board.item_re, block)
        if not m:
            continue
        cat_m = _CATEGORY.search(block)
        category = cat_m.group(1).strip() if cat_m else None
        if board.category_keep and category != board.category_keep:
            continue
        title = _TITLE.search(block)
        href = re.search(r'href="([^"]*' + board.item_re + r'[^"]*)"', block)
        if not (title and href):
            continue
        pages = _PAGES.search(block)
        date = _DATE.search(block)
        file_m = _FILE.search(block)
        items.append({
            'native_id': m.group(1),
            'detail_url': urljoin(BASE + '/research/', href.group(1).replace('&amp;', '&')),
            'published_raw': date.group(1) if date else None,
            'title': title.group(1).strip(),
            'category': category,
            'pages': int(pages.group(1)) if pages else None,
            'file_url': urljoin(BASE, file_m.group(1).replace('&amp;', '&')) if file_m else None,
        })
    return items
```

`domains/reports/pipeline/keywords.py`:

```python
"""고용 키워드 매칭. **판정은 하지 않는다.**

매칭은 네 기관 전부에 돌리고, 그 결과를 담을지 말지에 쓰는 것만 build 가
KDI·KIET 로 한정한다(스펙 §5-3). 둘을 나누지 않으면 KLI·KEIS 레코드의
matched 가 비어 주제 화면이 반쪽이 된다.
"""
from __future__ import annotations

import json
import re
from pathlib import Path

KEYWORDS_PATH = Path(__file__).resolve().parent.parent / 'data' / 'keywords.json'

_SPACE = re.compile(r'\s+')


def load_keywords(path: Path | str | None = None) -> dict[str, list[str]]:
    p = Path(path or KEYWORDS_PATH)
    return json.loads(p.read_text(encoding='utf-8'))


def _squash(s: str) -> str:
    """공백을 지운다 — '청년 고용'과 '청년고용'을 같은 것으로 본다."""
    return _SPACE.sub('', s or '')


def match(text: str, keywords: dict[str, list[str]] | None = None) -> list[str]:
    kw = keywords if keywords is not None else load_keywords()
    hay = _squash(text)
    hits: list[str] = []
    for topic, words in kw.items():
        if any(_squash(w) in hay for w in words):
            hits.append(topic)
    return hits
```

`domains/reports/pipeline/build.py`:

```python
"""raw + keywords.json → data/reports.json · abstracts.json · 결측률.

수집기는 게시판에 있는 것을 전부 raw 에 넣는다. 고용 여부를 가르는 것은 여기다.
경계가 여기 있는 이유는 비용이다 — 판정이 수집 안에 있으면 키워드 한 줄을 고칠
때마다 KDI·KIET 를 며칠에 걸쳐 다시 긁어야 한다. 여기서는 수십 초다.

  python -m domains.reports.pipeline.build
"""
from __future__ import annotations

import json
from pathlib import Path

from . import boards as boards_mod
from . import keywords as kw_mod
from . import store
from .models import Report

DATA = Path(__file__).resolve().parent.parent / 'data'


def judge(raw, board, kw) -> Report:
    text = ' '.join([raw.title, raw.abstract or '', ' '.join(raw.toc)])
    matched = kw_mod.match(text, kw)
    employment = bool(matched) if board.filter else True
    return Report(**raw.model_dump(), employment=employment, matched=matched)


def abstract_missing(reports: list[Report]) -> dict:
    out: dict[str, dict[str, dict]] = {}
    for r in reports:
        cell = out.setdefault(r.org, {}).setdefault(
            r.series, {'total': 0, 'missing': 0, 'rate': 0.0})
        cell['total'] += 1
        if not (r.abstract or '').strip():
            cell['missing'] += 1
    for series in out.values():
        for cell in series.values():
            cell['rate'] = cell['missing'] / cell['total'] if cell['total'] else 0.0
    return out


def build(raw_rows, boards, kw):
    by_id = {b.id: b for b in boards}
    kept: list[Report] = []
    for raw in raw_rows:
        board = by_id.get(raw.board)
        if board is None or not board.enabled:
            continue
        rec = judge(raw, board, kw)
        if rec.employment:
            kept.append(rec)
    kept.sort(key=lambda r: (r.published, r.id), reverse=True)
    abstracts = {r.id: {'abstract': r.abstract or '', 'toc': r.toc} for r in kept}
    return kept, abstracts, abstract_missing(kept)


def _light(r: Report) -> dict:
    """목록용 경량 레코드. 초록·목차는 abstracts.json 으로 간다."""
    d = r.model_dump(mode='json')
    d.pop('abstract', None)
    d.pop('toc', None)
    return d


def main(argv=None) -> int:
    kept, abstracts, missing = build(
        store.load_all_raw(), boards_mod.load_boards(), kw_mod.load_keywords())

    DATA.mkdir(parents=True, exist_ok=True)
    (DATA / 'reports.json').write_text(
        json.dumps([_light(r) for r in kept], ensure_ascii=False, indent=2) + '\n',
        encoding='utf-8')
    (DATA / 'abstracts.json').write_text(
        json.dumps(abstracts, ensure_ascii=False) + '\n', encoding='utf-8')

    last_path = DATA / 'last_run.json'
    last = json.loads(last_path.read_text(encoding='utf-8')) if last_path.exists() else {}
    last['reports'] = len(kept)
    last['abstract_missing'] = missing
    last_path.write_text(json.dumps(last, ensure_ascii=False, indent=2) + '\n',
                         encoding='utf-8')
    print(f'built: {len(kept)} reports')
    return 0


if __name__ == '__main__':
    raise SystemExit(main())
```

```python
"""게시판을 훑어 sources/raw/ 에 넣는다. **판정하지 않는다.**

  python -m domains.reports.pipeline.collect
  python -m domains.reports.pipeline.collect --board kli-research
  python -m domains.reports.pipeline.collect --dry-run

넓게 긁어 두고 판정은 build 가 한다. 수집기가 판정까지 하면 판정 기준을 고칠
때마다 다시 수집해야 하는데, 게시판 예의 때문에 그게 며칠이다.
"""
from __future__ import annotations

import argparse
import json
from datetime import datetime, timedelta, timezone
from pathlib import Path

from . import boards as boards_mod
from . import build as build_mod
from . import http, store
from .models import CUTOFF, RawReport, normalize_published, report_id
from .sites import kdi, keis, kiet, kli

KST = timezone(timedelta(hours=9))
DATA = Path(__file__).resolve().parent.parent / 'data'
SITES = {'kli': kli, 'keis': keis, 'kdi': kdi, 'kiet': kiet}
DETAIL_CAP = 40          # 회차당 기관별 상세 조회 상한
MAX_PAGES = 40


class NoThrottle:
    def wait(self) -> None:
        return None


def stub_record(item: dict, board) -> RawReport:
    """테스트용 최소 레코드. 파서 없이 오케스트레이션만 잴 때 쓴다."""
    published, precision = normalize_published(item['published_raw'])
    return RawReport(
        id=report_id(board.org, item['native_id']), org=board.org,
        board=board.id, series=board.series, title=item['title'],
        published=published, date_precision=precision,
        landing_url=item['detail_url'],
    )


def collect_board(board, *, fetch, throttle, detail_cap, existing,
                  parse_list=None, parse_detail=None):
    site = SITES[board.org]
    parse_list = parse_list or site.parse_list
    parse_detail = parse_detail or site.parse_detail
    known = {r.id for r in existing}
    result = {'ok': True, 'parsed': 0, 'added': 0, 'details': 0,
              'reached_cutoff': False, 'error': None}
    records: list[RawReport] = []
    details = 0
    try:
        for page in range(1, MAX_PAGES + 1):
            throttle.wait()
            html = fetch(site.list_url(board, page))
            items = parse_list(html, board)
            if not items:
                break
            result['parsed'] += len(items)
            stop = False
            for item in items:
                published, _ = normalize_published(item['published_raw'])
                if published < CUTOFF:
                    result['reached_cutoff'] = stop = True
                    break
                rid = report_id(board.org, item['native_id'])
                if rid in known:
                    continue
                if details >= detail_cap:
                    stop = True
                    break
                throttle.wait()
                detail_html = fetch(item['detail_url'])
                details += 1
                records.append(parse_detail(detail_html, item, board))
            if stop:
                break
    except Exception as exc:                       # noqa: BLE001
        result['ok'] = False
        result['error'] = str(exc)
    result['details'] = details
    if result['ok'] and result['parsed'] == 0:
        result['ok'] = False
        result['error'] = '목록을 받았지만 항목이 0건이다 — 마크업 변경 신호'
    return records, result


def write_last_run(results: dict, unregistered_found: list[str]) -> None:
    DATA.mkdir(parents=True, exist_ok=True)
    path = DATA / 'last_run.json'
    last = json.loads(path.read_text(encoding='utf-8')) if path.exists() else {}
    last['at'] = datetime.now(KST).isoformat(timespec='seconds')
    last['boards'] = results
    last['unregistered'] = unregistered_found
    path.write_text(json.dumps(last, ensure_ascii=False, indent=2) + '\n',
                    encoding='utf-8')


def main(argv=None, *, collectors=None, fetch=None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument('--board')
    ap.add_argument('--dry-run', action='store_true')
    args = ap.parse_args(argv)

    # collectors 를 주입하면 네트워크가 꺼진다 — 테스트가 밖으로 안 나간다.
    sites = SITES if collectors is None else collectors
    if not sites or args.dry_run:
        write_last_run({}, [])
        return 0

    getter = fetch or (lambda url: http.get_text(url))
    throttle = http.Throttle(delay=1.0)
    results: dict[str, dict] = {}
    for board in boards_mod.load_boards():
        if not board.enabled or (args.board and board.id != args.board):
            continue
        path = store.raw_path(board.id, board.org)
        existing = store.load_raw(path)
        records, result = collect_board(
            board, fetch=getter, throttle=throttle,
            detail_cap=DETAIL_CAP, existing=existing)
        merged, added = store.upsert(existing, records)
        result['added'] = len(added)
        store.save_raw(path, merged)
        results[board.id] = result

    write_last_run(results, [])
    build_mod.main()
    return 0


if __name__ == '__main__':
    raise SystemExit(main())
```

`SITES` 를 `collectors` 로 갈아끼우는 자리와, `--dry-run` 이 네트워크를 안 쓰는 자리를 테스트가 지킨다. 미등록 게시판 탐지(`boards.unregistered`)는 각 기관 메뉴 페이지를 한 번씩 받아 `write_last_run` 의 두 번째 인자로 넘긴다.

```javascript
// 역색인을 만들지 않는다. 2천 건 규모에서 문자열 스캔은 수십 밀리초다.
// 한국어 토큰화를 직접 하면 "청년고용"이 "청년 고용"에 안 걸리는 문제를
// 떠안는다 — 공백을 지워 그 문제를 아예 없앤다.
export function squash(s) {
  return (s || '').replace(/\s+/g, '');
}

const W = { title: 100, authors: 50, abstract: 10, toc: 10 };

export function searchReports(query, reports, abstracts) {
  const q = squash(query);
  if (!q) return [];
  const out = [];
  for (const r of reports) {
    const body = (abstracts && abstracts[r.id]) || null;
    let score = 0;
    let hit = null;
    if (squash(r.title).includes(q)) { score += W.title; hit = { where: 'title', snippet: '' }; }
    if ((r.authors || []).some((a) => squash(a).includes(q))) {
      score += W.authors;
      if (!hit) hit = { where: 'authors', snippet: '' };
    }
    // 본문 폴백: 초록 → 목차. 제목만 남는 경우는 위에서 이미 잡혔다.
    const sentence = body && sentenceWith(body.abstract, q);
    if (sentence) { score += W.abstract; hit = { where: 'abstract', snippet: sentence }; }
    else {
      const line = body && (body.toc || []).find((t) => squash(t).includes(q));
      if (line) { score += W.toc; hit = { where: 'toc', snippet: line }; }
    }
    if (hit) out.push({ report: r, score, hit });
  }
  return out.sort((a, b) => b.score - a.score
    || (a.report.published < b.report.published ? 1 : -1));
}

function sentenceWith(text, q) {
  if (!text) return '';
  for (const s of text.split(/(?<=[.!?。])\s+/)) {
    if (squash(s).includes(q)) return s.trim();
  }
  return '';
}
```

**주의**: 제목에서 걸렸는데 초록에도 걸리면 `hit` 이 초록으로 덮인다 — 위 코드가 그렇다. 테스트 `제목이 초록보다 위로 온다` 는 점수만 보므로 통과하지만, 스니펫 표시는 초록을 보여준다. 이것이 의도다(스펙 §6-1: 왜 걸렸는지 보이는 쪽이 낫다). 반대로 하고 싶으면 테스트를 먼저 고친다.
